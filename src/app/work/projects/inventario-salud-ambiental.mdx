## Descripción

**Lab Leonardo** es una aplicación web diseñada y desarrollada como Trabajo de Fin de Grado (TFG) para el ciclo formativo de grado superior en Desarrollo de Aplicaciones Web (DAW). Su objetivo principal es digitalizar y optimizar la gestión del inventario del laboratorio de química y salud ambiental del IES Leonardo Da Vinci, sustituyendo los métodos manuales y hojas de cálculo tradicionales por una plataforma centralizada y eficiente.

El sistema permite llevar un control riguroso de reactivos, materiales de vidrio, equipos de medición y medidas de seguridad, facilitando el trabajo diario de profesores y técnicos del laboratorio.

## Tecnologías Utilizadas

El proyecto se ha construido con un enfoque moderno y desacoplado, estructurado en una arquitectura cliente-servidor:

### Frontend
- **React 18** - Biblioteca principal para la interfaz de usuario.
- **TypeScript** - Tipado estático para un código robusto y libre de errores.
- **Vite** - Servidor de desarrollo y empaquetador ultrarrápido.
- **Tailwind CSS** - Estilos rápidos, modernos y adaptables.

### Backend
- **Laravel** - Framework de PHP utilizado para construir una API REST robusta y segura.
- **PostgreSQL** - Sistema de base de datos relacional para una gestión de datos sólida, alojada en Insforge.
- **Insforge Auth / JWT** - Autenticación y control de accesos seguro mediante tokens.

### Infraestructura y Despliegue
- **Docker & Docker Compose** - Contenedores para estandarizar y facilitar la ejecución del entorno local de desarrollo.
- **Vercel** - Despliegue optimizado del Frontend de React.
- **Render** - Alojamiento en la nube para la API del Backend en Laravel.

## Características Principales

El sistema incorpora las siguientes funcionalidades:

- **Control Completo de Inventario (CRUD)**: Gestión de reactivos químicos (indicando pureza, cantidad, fecha de caducidad y peligrosidad), material de vidrio y equipos.
- **Búsqueda y Filtros Avanzados**: Localización instantánea de reactivos y materiales mediante filtros por categoría, ubicación física en el laboratorio o estado de conservación.
- **Gestión de Roles y Permisos**: Roles específicos para administradores (profesores/técnicos) y usuarios de consulta (alumnos) para asegurar la integridad de la base de datos.
- **Sistema de Alertas**: Avisos visuales automáticos cuando un reactivo está próximo a caducar o las existencias están bajo mínimos.
- **Diseño Responsivo**: Interfaz completamente adaptada para su uso en tablets y dispositivos móviles directamente dentro del laboratorio.
